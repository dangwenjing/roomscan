# RoomScan — 安卓半自动室内平面图

绕房间走一圈,生成带真实尺寸(米)的 2D 平面图,导出 PNG / PDF 分享。两种模式:

| 模式 | 适用设备 | 怎么用 | 精度来源 |
|---|---|---|---|
| **测量模式** | 任何安卓机(含国行荣耀/华为) | 手机对准墙的方向按一下 + 输入墙长 | 你的激光尺/卷尺 |
| **AR 扫描模式** | 支持 ARCore 的机型 | 准星对准墙角按一下,不用量尺 | ARCore VIO 米制尺度 |
| **自动扫描(实验)** | 任何安卓机 | 站房间中央原地转一圈,不用量尺 | 相机高度 + 地板/墙交线的下倾角 |

### 自动扫描是怎么算的

照片本身没有尺度,但"手机离地高度"是一个免费的尺度:相机高 h,看到地板与墙的交线在视线下方 φ 度,
那面墙就在 `h / tan(φ)` 米远。转一圈,每个方位都算一个距离,得到一圈 360° 的"穷人版激光雷达"扫描,
再用 Douglas-Peucker 简化 + 主方向直角吸附 + 碎边剔除拟合成多边形(`geometry/RangeScanSolver.kt`)。
交线由 `vision/FloorBoundaryDetector.kt` 用颜色区域生长从画面底部往上找(不依赖神经网络),
地板颜色均匀、与墙有色差的房间效果好。预期误差 5–10%。

## 测量模式使用步骤

1. 站在房间任意一个墙角 A。像拍照一样举起手机,让取景框中央的竖线
   **沿着这面墙、指向下一个墙角 B 的方向**。按【锁定方向】。
2. 输入这面墙 A→B 的长度(米),用激光尺或卷尺量。确定。
3. 走到墙角 B,对准下一面墙 B→C 的方向,按【锁定方向】,输入长度。
4. 重复直到最后一面墙(回到 A 的那面)也录完。屏幕下方会实时显示**闭合差**
   ——理论上应为 0,几厘米很正常,超过 30 cm 说明有一面墙输错了,【撤销】重录。
5. 【完成】→ 平面图(已做 Bowditch 闭合平差)→ 导出。

方正的房间保持【直角吸附】开启;有斜墙的房间关掉它。
方向用的是陀螺仪(不用磁力计,室内磁场干扰不影响),一间房几分钟内漂移可忽略。

## 原理一句话

纯照片恢复不出绝对尺寸(单目尺度歧义)。ARCore 用相机 + IMU 融合(VIO)
给出真实米制坐标,所以对墙角做 `hitTest` 拿到的 3D 点就是真实世界坐标,
连起来直接就是准确的平面图,不需要任何参照物。

## AR 模式(需 ARCore)

1. Android Studio(Koala 或更新)打开本目录 → 等 Gradle 同步完成。
2. 插上一台 **支持 ARCore 的安卓手机**(查表:https://developers.google.com/ar/devices),
   开 USB 调试,点 Run。
3. 使用流程:
   - 打开 app,对着地板缓慢晃动手机几秒,直到提示变成"把准星对准…"。
   - 走到第一个墙角,把屏幕中央准星对准 **地板与墙面的交线角**,按【添加角点】。
   - 沿着墙顺时针(或逆时针)走,每个墙角点一次。看到画面上蓝线把墙连起来即正确。
   - 点错了按【撤销】。最后一个角点不用连回起点,app 会自动闭合。
   - 按【完成】→ 看到平面图、周长、面积 → 【导出 PNG】/【导出 PDF】→ 微信/邮件发给自己。

## 精度相关

- 典型精度 **1–3 cm/米**,整间房总尺寸误差通常在 5 cm 以内。
- 影响最大的几个因素:光线充足、地面有纹理(纯白瓷砖/反光地板会差)、
  走动平稳不要甩手机、点角点时离墙角 1–2 m 左右。
- `FloorPlanActivity.SQUARE_UP = true` 会把接近 90° 的墙角吸附成直角(容差 12°),
  绝大多数房间更准;有斜墙的房间请改成 `false`。

## 代码结构

```
app/src/main/java/com/example/roomscan/
├── HomeActivity.kt            入口:选择模式,检测 ARCore 可用性
├── MeasureActivity.kt         测量模式:陀螺仪方向 + 手动墙长,CameraX 取景辅助
├── MainActivity.kt            AR 扫描界面:ARCore session、hitTest 采集角点
├── FloorPlanActivity.kt       结果界面:显示平面图 + 导出
├── geometry/FloorPlan.kt      几何模型:墙长、周长、面积(鞋带公式)、直角吸附
├── geometry/Traverse.kt       导线计算:方向+距离 → 角点,闭合差,Bowditch 平差
├── rendering/
│   ├── BackgroundRenderer.kt  相机画面渲染(GLES20 外部纹理)
│   ├── OverlayRenderer.kt     在 AR 画面上画已采集的角点与墙线
│   └── ShaderUtil.kt
├── view/FloorPlanView.kt      2D 平面图绘制(建筑图样式:墙线、尺寸标注、比例尺)
└── export/PlanExporter.kt     PNG / PDF 导出 + 系统分享
```

## 后续可以加的

- **门窗**:再加一个模式,对准门框两边各点一下,记录在哪面墙、离起点多远。
- **多房间拼接**:同一个 ARCore session 里连续扫几个房间,坐标系是共享的,直接叠加即可。
- **DXF 导出**:给 CAD 用,格式简单(几十行代码就能写 LINE 实体)。
- **墙厚**:平面图默认画单线;需要双线墙的话给 `FloorPlanPainter` 加一个外扩多边形。
- **全自动**:在 Depth API 支持的机型上,用深度图 + 平面检测自动找墙面交线,
  但这是另一个量级的工作(鲁棒性问题多),建议先把半自动版本用顺手。

## 已知限制

- AR 模式仅支持 ARCore 设备;国行荣耀/华为请用测量模式。
- 单层楼、单个房间多边形;复杂凹形房间也能画,但点的顺序要沿墙连续。
- 本工程未在本地编译验证(我没有 Android SDK 环境),首次同步若有依赖版本冲突,
  优先调整 `app/build.gradle.kts` 中的 AGP / Kotlin 版本号。
